# Time sheet app 

## About the app
This app helps to track the daily time spent by each employee on a particular task along with providing general overview to the managers.

## Features
- Data input for each user.
- Secure Login/Logout functionality.
- Management level Overview along with approvals/rejections.
- Edit/Delete functionality.
- Historical data fetching.

## How to Setup

### Frontend
Navigate to the frontend folder and run the following command.

`npm install`
`npm run dev`


### Backend
Navigate to the backend folder and run the following commnad.

`pip install -r requirements.txt`
`uvicorn main:app --port 5000 --reload`
